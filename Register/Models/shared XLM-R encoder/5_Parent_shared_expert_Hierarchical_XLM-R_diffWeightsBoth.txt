Child classifiers
For NA it is nn.Linear(256, 3) and so on for others. (3: ne, nb, sr)

Final output dimension is parent_logits + child_logits =  9 + 16 = 25

loss

parent_loss = BCEWithLogitsLoss(parent_logits, parent_labels)
child_loss = BCEWithLogitsLoss(child_logits, child_labels)

loss = (
    parent_weight * parent_loss
    +
    child_weight * child_loss
)


Each loss is separately averaged. (due to using BCEWithLogitsLoss())
